## 🚀 Installation

Clone the repository:

```bash
git clone https://github.com/Prachipandey28/prachi_portfolio
```

Go to project folder:

```bash
cd prachi_portfolio
```

Install dependencies:

```bash
npm install
```

Run development server:

```bash
npm run dev
```
